# Сценарии проверки

Для знакомства с проектом: [проверка за 5 минут](judge-runbook.md).
Все приведённые ниже данные вымышлены. Облачные ключи для [локальной демонстрации](local-demo.md) не нужны.

## Контрольная формула

| Сценарий | ЖК / ID | Подтверждено | Ожидание |
| --- | --- | --- | --- |
| A | Янтарный берег · `demo-complex-01` | R2 + R3, основание неизвестно | **35 · YELLOW** |
| B | Кедровый квартал · `demo-complex-02` | R1 + R2 + R3 | **70 · RED** |
| C | Солнечный склон · `demo-complex-03` | Применимая гарантия, R3 | **10 · GREEN** |

Это исходное состояние seed. Действия аналитика сохраняются, поэтому уже
использованный локальный набор может отличаться. Повторный импорт не сбрасывает
решения; для обычной проверки используйте новый материал, а не удаление данных.

## Приоритет, решение и повтор

1. Добавьте новое учебное объявление через «Реклама» по примеру из runbook.
2. Дождитесь автоматического анализа: гипотезы R2/R3 могут дать приоритет **35**.
   Подтверждённый риск до решения остаётся прежним.
3. В одной форме подтвердите проверенные признаки и сохраните комментарий.
   Сервер обновит доказательства и подтверждённые факторы одной операцией.
4. Добавьте тот же текст с другой платформой и ссылкой: одна карточка, два
   оригинала, без второго вклада того же фактора и без отмены решения.
5. Для существенно изменившегося текста/нового фото появится новая ревизия,
   которую можно проверить заново. Прежние записи остаются в истории.

## Недостаточно данных и параллельная работа

- Выберите «Недостаточно данных»: итог автоматически становится «Оставить для
  проверки», недостаточный признак не подтверждается.
- Откройте материал в двух вкладках и сохраните разные решения. Устаревшая
  версия получает конфликт; черновик сохраняется, повторного решения без
  явного обновления и действия аналитика нет.
- Неудачный анализ показывает ошибку. Явный повтор доступен для failed;
  ожидание квоты и неподдерживаемое внешнее видео имеют отдельные состояния.

## Сигнал и история

После подтверждения создайте сигнал. Проверьте передачу, возврат с причиной,
повторную передачу, подтверждение и PDF. Снимок сигнала не меняется от простого
обновления карточки. Если исходные факторы изменились, устаревшее подтверждение
блокируется и требуется новая проверка.

## Рекламный след

Для одного учебного ЖК добавьте два объявления с разными аккаунтами и ссылками:

> DEMO — вымышленное объявление. Контакт +7 (000) 000-00-01.

> DEMO — другой вымышленный аккаунт. WhatsApp https://wa.me/70000000001

Это учебные реквизиты, обращаться по ним не нужно. В материале откройте
«Рекламный след и файлы исходных объявлений», сравните совпадение и сохраните
решение. Совпадение контакта не доказывает общего владельца или нарушение
и не добавляет баллы. [Подробности](advertising-trace.md).

## Доступ и ограничения

Без входа API рабочего пространства возвращает 401, без допустимой роли — 403.
Гипотезы и отсутствие записи в справочнике не превращаются в подтверждённый R1.
При недоступном провайдере оригинал остаётся сохранённым. Учебные ответы не
являются результатом настоящего распознавания изображений или правовой проверкой.

Реализация и результаты: [совместный отчёт](unified-advertising-integration-report.md),
[контракт](material-workflow-contract.md), [правила R1–R6](risk-rules.md).
