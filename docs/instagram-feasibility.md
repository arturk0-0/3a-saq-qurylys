# Instagram и таргетированная реклама: фактическая доступность

Проверка 17 октября 2026 из среды Codex. Приоритет Instagram-таргета задан
владельцем; этот документ не подменяет его обычным поиском постов или Telegram.
Ключи Meta, платные поставщики и рекламные кабинеты для проверки не использовались.

## Что установлено

1. Официальная [справка Ads Archive](https://developers.facebook.com/docs/graph-api/reference/ads_archive/)
   получена HTTP 200 и прочитана. В параметре `ad_reached_countries` прямо указано:

   > Ads that did not reach any location in the EU will only return if they are
   > about social issues, elections or politics.

   API имеет `HOUSING_ADS`, `ALL` и фильтр `publisher_platforms=INSTAGRAM`,
   но это **не отменяет ограничение охвата**. Обычная реклама новостроек,
   показывавшаяся только в Казахстане, не получает гарантированного доступа
   через этот API. Объявление, которое также показывалось в ЕС, — другой случай;
   невозможность вообще получить любое казахстанское объявление не утверждается.
   Для реальных API-вызовов также нужны подходящие Meta access token/доступы.
2. [Веб-библиотека с выбором Казахстана](https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=KZ&search_type=keyword_unordered)
   и страница `facebook.com/ads/library/api/` из этой среды ответили **403**.
   Это отказ доступа, не нулевая выдача. В браузере владельца доступность может
   отличаться; она здесь не проверена. Не применялись обход login/CAPTCHA,
   ротация прокси, скрытые GraphQL endpoints или извлечение browser cookies.
3. Официальная [Hashtag Search](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-facebook-login/hashtag-search)
   получена HTTP 200 и прочитана: поиск публичных media по hashtags, Business/Creator
   account, до 30 уникальных hashtags за rolling 7 дней; требуется App Review,
   Instagram Public Content Access и `instagram_basic`. Stories hashtags
   не поддерживаются. **Это не API всей таргетированной рекламы региона.**
4. Обычная публичная страница официального аккаунта Instagram вернула HTTP 200,
   но видимая страница содержит Log In/Sign Up. Полноценная выгрузка рекламных
   креативов не получена. Один HTTP 200 не доказывает работающий сборщик.
5. Переменных Meta/Facebook/Instagram credentials в текущей среде не обнаружено
   (проверены только имена/наличие, без чтения или вывода секретов).

Временные HTML/текстовые материалы чтения документации находятся только в
`/tmp/saq-instagram-feasibility/`; исходники чужих объявлений не добавлены в Git.

## Решение для реализации

- **MON-IG-01 завершён**: доступность проверена и ограничение подтверждено
  официальным источником. Это не завершение Instagram-интеграции.
- **MON-IG-02 остаётся prerequisite**: нужен источник, реально отдающий обычные
  Instagram Ads по Казахстану в разрешённом режиме — согласованный поставщик/API,
  либо предоставленный экспертами разрешённый набор/экспорт. До выбора проверить
  покрытие страны/языка/креатива, цену, условия использования, sample и provenance.
  Покупки, регистрация сторонних аккаунтов и передача паролей не выполняются.
- Публичные индексируемые Instagram-посты можно находить обычным web search,
  но такой источник помечать именно как discovery/поисковый фрагмент. Нельзя
  показывать его как подтверждение рекламного показа/таргетинга или полный охват.
- Общие очередь, дедупликация, аудит, AI-гипотезы и ручная проверка разрабатываются
  независимо: они понадобятся и выбранному Instagram-поставщику. Поддерживаемые
  публичные адаптеры не называются заменой Instagram-таргета.

Нельзя закрывать задачу автоматического Instagram-мониторинга демонстрационным
ответом, поисковой ссылкой или HTTP 200 страницы входа. R1–R6 и проверку
правового основания эта проверка доступности не меняет.
