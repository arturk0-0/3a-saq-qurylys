# SAQ QURYLYS — показ организаторам на 5–7 минут

## Как открыть

Опубликованный сайт: **https://saq-qurylys.web.app**. Нужны Интернет и выданные
владельцем приватно данные входа аналитика. Не нужны Docker, Admin JSON или ключ
Gemini на компьютере зрителя. API обслуживается отдельным Cloud Run:
https://saq-qurylys-api-722228028571.europe-west1.run.app.

Для самостоятельного локального запуска используйте [README](../README.md) или
[Windows/Docker Desktop](windows-start.md): это локальные UI/backend-процессы с
собственной разрешённой облачной конфигурацией. Без Firebase ожидаются публичный
health и экран настройки, а не каталог с фальшивой авторизацией.

Исправления PR не считаются опубликованными. Владелец должен связать сдаваемый
commit/tag, прошедший CI, версию Hosting и ревизию Cloud Run. В этой задаче код
проверялся локально от security-базы `d579566`, инфраструктура не обновлялась.

## Перед показом — владелец

- Зафиксировать сдаваемый SHA и дату проверки; подтвердить фактические URL/версию
  после публикации, вход на другом устройстве и доступность репозитория без входа
  до установленного организаторами срока. Уточнить точный срок у организаторов.
- Выдать отдельную DEMO-учётную запись с разрешённой ролью; не помещать пароль в
  Git, инструкцию, скриншоты или запись экрана. Подготовить вкладки входа и каталога.
- Проверить наличие 8 вымышленных ЖК и 12 объявлений; A = 35/YELLOW,
  B = 70/RED, C = 10/GREEN **в исходном seed**. Shared DEMO меняется действиями
  аналитиков; create-only seed их не сбрасывает. Не запускать seed для очистки.
- Выбрать отдельный учебный объект с подтверждённым R3, неизвестным R2 и баллом 10.
  Исходный seed предлагает «Горная мозаика», но в живой среде R2 уже подтверждали;
  сначала проверить текущее состояние. Не снимать реальные решения ради эффекта
  10 → 35; при другом состоянии честно показать текущий серверный результат.
- Для одной новой генерации заранее подтвердить бюджет/квоту. Текущая выбранная
  владельцем модель — `gemini-3.5-flash-lite`; metadata 200 не доказывает, что
  generateContent или image-анализ доступны. Все платные проверки делает владелец.
- Заранее скачать проверенный DEMO PDF и подготовить честно подписанную запись
  предыдущего успешного прогона как резерв. Запись не выдавать за live-результат.

## Порядок показа — около 6 минут 30 секунд

| Время | Действие | Что показать/сказать |
| --- | --- | --- |
| 0:00–0:35 | Войти, открыть обзор | ВКО; все записи вымышлены и помечены DEMO. Это приоритет ручной проверки, не вывод о незаконности и не отправка в органы. |
| 0:35–1:10 | Поиск/фильтр, открыть A/B/C | A: неизвестное основание не стало R1; B: 70/RED с R1+R2; C: действующая применимая гарантия, 10/GREEN. Источник каждого фактора открывается отдельно. |
| 1:10–2:00 | Выбранный ЖК → «Объявления» → «Добавить» | Новая синтетическая публикация, точная ссылка, вымышленный аккаунт и дата. Сохранить и сверить текст с оригиналом. |
| 2:00–2:50 | «Скриншоты и AI-анализ» → «Текст объявления» → «Анализировать выбранный источник» | Один настоящий запрос владельца. Развернуть строку запуска: модель, неопределённость, точная цитата; гипотеза ещё не факт. Если нет поддержанных гипотез — честно показать это и перейти к ручной проверке. |
| 2:50–3:30 | «Рассмотреть гипотезу» → «Принять к проверке» с обоснованием | Принятие AI не подтверждает источник и не меняет балл. «К доказательству» открывает выбранный источник, включая прямую ссылку/reload. |
| 3:30–4:15 | «Проверить источник» → сверить оригинал → отметить предложение платежа → сохранить | Источник проверен человеком; балл по-прежнему 10 при исходном R3-only. Затем «Решение по фактору R2» → «Подтвердить фактор», выбрать именно проверенное доказательство, обоснование → сохранить. Только теперь backend даёт 35/YELLOW. |
| 4:15–5:30 | «Создать сигнал» → черновик → передать → вернуть с причиной → повторно передать → подтвердить | Каждый шаг отдельный, видны автор/время/причина. Подтверждение сигнала не изменяет R1–R6 и не отправляет документ в органы. |
| 5:30–6:10 | История сигнала и «Скачать PDF» | История не должна показывать общую ошибку. Открыть скачанный файл: DEMO, статус, 35 баллов, источник/цитата, reviewer/даты. Это серверный снимок; новая карточка не переписывает старый снимок. |
| 6:10–6:30 | Завершить | Ограничения: внутренний DEMO-реестр, нет закрытых госреестров; AI ошибается, решения принимает человек. Назвать сдаваемый SHA и путь README/runbook. |

Пример **нового синтетического текста**, который можно изменить перед показом:

> DEMO. Строящийся ЖК Горная мозаика. Для бронирования внесите депозит
> 135 000 тенге. Вымышленное учебное объявление.

Учебная ссылка: `https://demo.invalid/judge-review`; это реквизит вымышленного
источника, не рабочий внешний реестр. Не подставляйте реальные обвинения/персональные
данные. Для проверки внешнего открытия нужен собственный доступный синтетический
источник владельца. Сохранённый текст и цитата должны совпадать буквально.

## Резерв при недоступном Gemini

1. Показать полученную ошибку модели/квоты/сети. Исходное объявление остаётся
   сохранённым, баллы не меняются. Не нажимать анализ многократно: timeout не
   гарантирует, что генерация не состоялась или не была оплачена.
2. Сказать: «Сейчас AI недоступен; далее показываем ручную работу аналитика».
3. В том же ЖК открыть **Доказательства → Добавить источник**. Выбрать
   **«Текст объявления»**, связать именно новое объявление, указать ту же
   исходную ссылку, точную цитату и время фиксации. Сохранить источник.
4. Отдельно проверить источник/предложение платежа, затем подтвердить R2
   с выбранным источником. Backend рассчитывает балл; продолжить сигнал и PDF.
   Это ручной сценарий, не результат Gemini. Ранее сохранённую гипотезу можно
   показать только с её настоящей датой и явной пометкой, что анализ не новый.
5. Если недоступен и Firebase/API, остановить live-сценарий. Показать заранее
   подписанную запись/проверенный PDF и исходники. Локальные QA adapters не
   заменяют рабочий сервис и не включаются на опубликованном сайте.

## При ошибке во время показа

- **409:** не перезагружать вкладку с введённым текстом. Использовать «Обновить
  данные ЖК»/«Обновить источник»/«Обновить результаты» или «Обновить» у сигнала,
  сверить свежую версию и явно повторить решение. Никакая кнопка GET refresh
  сама не подтверждает фактор/источник/сигнал. Если источник уже связан с
  подтверждённым фактором, сначала пересмотреть фактор.
- **История/индекс:** сохранить код обращения, повторить загрузку один раз;
  владельцу проверить готовность индексов и безопасные логи. Не объявлять причину
  ошибки доказанной только по общему сообщению.
- **PDF:** повторить после ошибки; HTML-ответ не должен скачиваться как `.pdf`.
  Печать карточки — явный резерв, а не подтверждение работы серверного PDF.
- **Потеря авторизации:** войти снова. Наличие health 200 не подтверждает роль
  аналитика, доступ к БД/Storage или работоспособность Gemini.

## Обязательная ручная приёмка владельцем после публикации

Записать результат каждого пункта и сдаваемый SHA/Hosting/Cloud Run revision;
до проверки это **не пройденные** облачные тесты.

| Шаг | Ожидаемый результат |
| --- | --- |
| Новый браузер/инкогнито, прямой `/signals/<id>` без входа | Только вход; API без token — 401; роли/клиентские заголовки не обходят backend |
| Вход, выход, отозванная/истёкшая сессия | Разрешённый аналитик входит; после выхода/401 рабочие данные и навигация скрыты |
| Новое объявление и новый RU/KZ текст | Оригинал сохранён; новая генерация владельца даёт проверяемую цитату/неопределённость или честный отказ, без автоматического подтверждения |
| Новый синтетический скриншот | JPEG/PNG/WebP приватно загружен/открыт; неверный формат, >6 MiB, повреждённый файл отвергнуты; реальный image-анализ сверяется глазами |
| AI → источник → фактор | 10 → 10 → 35 при выбранном исходном R3-only; балл приходит с сервера |
| История ЖК/сигнала | Загрузка и следующие страницы работают; индексы READY, нет повторов/утечек другого сигнала |
| Полный цикл сигнала и два одновременных окна | Конфликт 409 понятен; введённый текст сохраняется при обновлении, автоматического решения нет |
| Cloud Run PDF | Настоящий PDF открывается; русские/казахские буквы, DEMO, ссылки, reviewer/время, правильный снимок; скачивание закрыто без авторизации |
| Storage/rules/IAM | Исходники и PDF не доступны анонимно/по клиентскому SDK; использование backend не требует ослабления rules |
| Второй Windows-ПК + Docker Desktop | Чистый clone согласованного SHA, install по lockfiles, оба healthy, вход/сценарий/PDF. Linux-прогон этого не подтверждает |
| Телефон и клавиатура | 320/375px: формы и действия доступны; фокус понятен; таблица прокручивается; back/forward/reload сохраняют нужный маршрут |
| Сдача исходников | Review цепочки PR, CI именно финального SHA, анонимная доступность GitHub, согласованный commit/tag передан организаторам |
