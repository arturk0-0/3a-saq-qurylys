# Проверка проекта за 5 минут

**SAQ QURYLYS · ALEteam.** Этот маршрут соответствует текущей единой «Рекламе».
Для самостоятельной проверки достаточно [локального запуска](../README.md#быстрый-запуск).
Облачные ключи и регистрация в Firebase не требуются.

## 1. Войти и посмотреть обзор

Откройте http://localhost:5173. Почта `analyst@example.test`, пароль `demo-demo`.
В обзоре — 8 учебных ЖК. Для каждого отдельно показаны **приоритет проверки**
и **подтверждённые риски**. Нерассчитанный приоритет не заменяется нулевым риском.

В исходном учебном наборе есть три контрольных примера:

| ЖК | Что подтверждено | Оценка |
| --- | --- | --- |
| Янтарный берег | Предложение платежа и реклама строящегося жилья | **35 · жёлтая зона** |
| Кедровый квартал | Дополнительно подтверждено отсутствие применимого правового основания | **70 · красная зона** |
| Солнечный склон | Применимая гарантия и только реклама строящегося жилья | **10 · зелёная зона** |

[Точная формула R1–R6](risk-rules.md). Учебные названия не относятся к реальным нарушителям.

## 2. Добавить материал и увидеть автоматический анализ

Откройте **Реклама → Все материалы → Добавить материал**.
Выберите учебный ЖК «Горная мозаика», укажите вымышленный аккаунт, текущую дату
и ссылку `https://demo.invalid/reviewer-example`. Вставьте текст:

> DEMO. Квартиры в строящемся доме. Для бронирования внесите депозит
> 135 000 тенге. Вымышленное объявление для проверки приложения.

Сохраните, найдите материал по тексту и нажмите **«Проверить материал →»**.
Анализ запускается автоматически. Если он ещё в очереди, обновите материал;
отдельную кнопку запуска ИИ искать не нужно.

В локальном режиме результат формируют явные учебные правила по словам, не
Gemini. Можно проверить сам путь обработки, цитаты и работу с решениями.
Неподтверждённые признаки повышают приоритет, но не подтверждённый риск ЖК.

## 3. Сохранить одну проверку

На той же странице сверяются текст, исходная публикация, ЖК и документы.
Выберите решение по каждой гипотезе, добавьте комментарий и нажмите
**«Сохранить проверку»**. При недостатке данных материал остаётся для проверки.

В чистом наборе «Горная мозаика» имеет подтверждённый R3 и 10 баллов. Явное
подтверждение R2 по новому предложению депозита даёт **35**, а не прибавляет
баллы за каждую публикацию. История сохраняет комментарий и время решения.

Чтобы проверить повторы, добавьте тот же текст для того же ЖК с другой
платформой и ссылкой. Останется одна карточка с несколькими оригиналами;
прежнее решение не исчезнет от появления дубликата.

## 4. Получить сигнал и PDF

Из проверенного материала перейдите по ссылке создания сигнала. Укажите
обоснование, передайте сигнал на проверку, подтвердите или верните с причиной.
Откройте историю и скачайте PDF.

PDF содержит сохранённый снимок риска и доказательств. Решение по сигналу
не пересчитывает R1–R6 и не отправляет документ в государственные органы.

## 5. Открыть дополнительные возможности

- **Реклама → Источники и расписание:** Telegram/Instagram, параметры источников,
  интервалы и история сборов. В локальном режиме сбор возвращает учебный материал.
- **Карточка ЖК / Организации:** документы, рекламный след, юридический застройщик
  и уполномоченная компания, известные сведения и ссылки на источники.
- **Обзор / Реестр ЖК → карта:** условные объёмные здания по известным координатам.
  В локальном режиме внешняя подложка недоступна; это описано в [ограничениях](local-demo.md).
- **Дрон-инспекция:** фото, визуальный чек-лист и решение эксперта. В локальном
  режиме снимок сохраняется без распознавания; результат не влияет на рекламный риск.
