# Сигналы и PDF

Из карточки ЖК выберите «Создать сигнал», укажите заголовок и основание.
Сервер сохраняет черновик со снимком карточки, застройщика, рассчитанного риска,
ссылок, выдержек, дат, SHA-256 и проверивших источники аналитиков.

Переходы: draft → pending_review → confirmed либо returned.
Returned → pending_review сохраняет новый снимок актуальных данных.
Для каждого перехода обязательны версия и обоснование; автор/дата — серверные.
Подтверждённый сигнал неизменяем. Все версии доступны через
GET /api/v1/signals/{id}/revisions/{version}; история — /history.
Проверяющий может быть автором: требование второго пользователя для сигнала
не установлено спецификацией. Командное code review — отдельный процесс.

Подтверждение устаревшего снимка блокируется 409: верните сигнал, проверьте
изменения, повторно передайте на проверку. Подтверждение не меняет факторы и
ничего не отправляет во внешние органы. Черновики/возвращённые сигналы тоже
можно экспортировать; их статус явно указан.

GET /api/v1/signals/{id}/report выдаёт настоящий PDF WeasyPrint.
Параметр format=html выдаёт экранированный HTML для скачивания.
Оба endpoint требуют авторизацию. Кэширование запрещено; внешние и локальные
ресурсы в PDF блокируются URL fetcher, пользовательский HTML экранируется.
Снимок ограничен 250 КБ, цитаты до 2000 символов с явной отметкой сокращения.
Оригиналы доступны в объявлениях/доказательствах. Два параллельных PDF на процесс,
остальные запросы получают 429. Все страницы PDF имеют метку DEMO.

В Docker/CI устанавливаются Pango, HarfBuzz и DejaVu. На Linux без Docker:
sudo apt-get install libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz-subset0 fonts-dejavu-core
На Windows предпочтителен Docker; для native WeasyPrint понадобятся системные
библиотеки по официальной инструкции WeasyPrint. Отсутствие библиотек даёт 503.

Проверено: реальные байты PDF, безопасный HTML, версии, возврат/повторная проверка,
снимок при смене score, закрытые endpoints. Полный API-тест нового объявления
до PDF использует явно тестовые Firebase/Gemini adapters, а не live облако.
