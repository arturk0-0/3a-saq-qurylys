## Границы и оставшаяся приёмка

Gitleaks ищет известные формы секретов и не доказывает отсутствие любых
персональных данных или произвольных новых форм ключей. Он не проверяет чужие
форки, недоступные/удалённые refs, вложения Issues/чатов и облачные объекты.
Публичные browser Firebase-настройки сами по себе не дают Admin-доступа.

BE-13 остаётся открыт: владелец проверяет реальные Storage IAM/public access,
Firebase rules/роли, Secret Manager bindings, действующие лимиты и защищённые
загрузки на опубликованной версии. При обнаружении реального ключа — сначала
отозвать его у провайдера, затем согласовать очистку истории; не публиковать ключ
в отчёте и не выполнять force-push без отдельного решения.

Повторять сканирование после новых веток/коммитов и перед публичной сдачей.
Установка инструмента нужна только разработчику, не пользователю приложения.
