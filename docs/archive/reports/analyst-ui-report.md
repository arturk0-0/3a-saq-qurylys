# Интерфейс аналитика · 18 октября 2026

По прямому поручению владельца выполнена frontend-задача целиком. Backend,
контракты API, реальные записи, R1–R6, провайдеры, расписание и лимиты не менялись.

## Что изменено

- Из шапки удалён общий DEMO-баннер; контекст — «Рабочее пространство · ВКО».
- Очередь начинается с публикаций. Большой блок приоритета Instagram удалён;
  подключения, текущие квоты/баланс и покрытие находятся только в
  «Источники сбора → Подключения и лимиты», изначально свёрнуты.
- Из кнопок/обычных подсказок убраны надписи о платных запросах, серверном worker
  и технической настройке. Нейтральный запуск «Проанализировать с AI» остаётся
  отдельным явным действием; автоанализ по умолчанию выключен, серверные квоты
  и резерв поисков сохранены. Обновление экрана не вызывает AI/поиск.
- Причины отбора/повторные инструкции находятся под раскрываемыми заголовками;
  добавлена короткая анимация с поддержкой reduced motion.
- В решениях/истории/источниках/сигналах/совпадениях вместо UID отображаются
  названия через общий ActorName. Для текущего пользователя используется имя
  профиля, если имени нет — «Вы». Для неизвестного другого пользователя —
  «Аналитик»: имя не выдумывается и список чужих Auth-профилей не запрашивается.
  Сервисный сборщик и известный вымышленный эксперт обозначены отдельно.
- Общие повторные предупреждения DEMO убраны. Вымышленные объекты, объявления
  и сигналы получают компактную локальную пометку «Учебная запись»; реальные
  записи её не получают. Сырые исходники/цитаты и аудит не переписываются.
  Реальные публикации по-прежнему нельзя привязать к учебному ЖК.
