## Во время показа

Если показывается MON, сначала выполнить дополнительную подготовку:

- [ ] Опубликован именно интеграционный SHA; MON API защищён, индексы READY.
- [ ] SearchAPI secret задан на backend; резерв не ниже 20, лимит 2/сутки,
  авто-AI выключен. Баланс в UI — перед последним поиском, не текущий онлайн-баланс.
- [ ] Сохранена безопасная находка для просмотра без нового SearchAPI/AI запроса.
  Указаны источник/дата, нет обвинений; real-находка не присоединена к DEMO ЖК.
- [ ] Для заявления «по расписанию» есть реальный успешный Job/Scheduler-запуск;
  одно сохранение источника и открытая вкладка этого не доказывают.
- [ ] Для Telegram указан проверенный публичный канал: встроенного списка нет.
  Сбор последних доступных текстов не выдаётся за поиск по всему Telegram.

- [ ] Сказать DEMO, ВКО, «приоритет проверки», отсутствие правового заключения
  и автоматической отправки. Не использовать реальные обвинения.
- [ ] Перед анализом сверить «Источник анализа» и «Будет проанализирован».
  Загрузка скриншота сама анализ не запускает.
- [ ] Показать отдельно принятие гипотезы, проверку источника и решение
  по фактору. Балл берётся с сервера; сигнал — ещё одно отдельное решение.
- [ ] В «Рекламном следе» объяснить границы: контакты из сохранённых текстов,
  ограниченная выборка; совпадение не доказывает собственность/незаконность.

## Если что-то не работает

| Ситуация | Действие |
| --- | --- |
| Gemini: ошибка, квота, задержка или пустые гипотезы | Назвать результат; не запускать повторно ради тайминга. Ручной источник → проверка → фактор → сигнал. Не выдавать ручной вывод за AI. |
| Конфликт версий | Оставить вкладку/введённые заметки, нажать предусмотренное «Обновить…», сверить новую версию, повторить решение явно. Обновление не подтверждает данные. |
| История/PDF недоступны | Один явный повтор; при неуспехе показать резерв с датой. Зафиксировать безопасный код обращения без токенов/исходных персональных данных. |
| Недоступны Firebase/API | Остановить live-цепочку; явно назвать запись/снимок/проверенный PDF резервом. Не подключать QA-авторизацию к опубликованному приложению. |
| Пустой рекламный след | Назвать пустую/ограниченную выборку; использовать подготовленную пару только если она реально доступна в этой версии. Не заявлять, что связей нет. |
