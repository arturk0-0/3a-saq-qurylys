## Что эти проверки подтверждают

Проверены интерфейс, API, серверный скоринг, транзакции решений, сохранность
оригиналов, история, приватные загрузки и формирование настоящего PDF.
В тестах внешние сервисы заменены явными адаптерами; локальный режим использует
учебные данные и отдельное хранилище. Успех тестов не доказывает качество модели
или доступность каждого внешнего источника.
