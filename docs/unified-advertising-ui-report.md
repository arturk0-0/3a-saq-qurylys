## Что изменено

- В меню один раздел **Реклама**. `/advertising` содержит ровно две вкладки:
  «Все материалы», «Источники и расписание». История запусков находится внутри
  источников. Поиск, фильтры, сортировка и cursor принадлежат серверу; URL хранит
  состояние. Материал объединяет публикации, а не дублируется по числу оригиналов.
- `/advertising/materials/:id`: сохранённый исходный текст, платформа/автор/даты,
  безопасная внешняя ссылка, приватные изображения через авторизованный запрос,
  пагинация оригиналов. Цитата выбирает точный оригинал, в том числе отсутствующий
  на загруженной странице, через отдельный endpoint occurrence. Недоступное
  изображение/внешнее видео не выдаются за просмотренный AI материал.
- Гипотезы и причины показываются как предварительные. Есть выбор ЖК, решения
  по гипотезам/факторам и общий комментарий. **Одно сохранение** вызывает только
  `POST /materials/:id/review`: expectedVersion, revisionId, complexVersion,
  disposition, решения и requestId. Нет цепочки промежуточных accept/attach/factor.
  Backend остаётся единственным источником расчёта R1–R6 и риска.
- После потерянного ответа повтор использует прежний requestId и payload.
  409 сохраняет введённое; нужны явное обновление, подтверждение прочтения новой
  версии и новое нажатие сохранения. Ничего автоматически не пересылается.
  422 сохраняет черновик и даёт понятную ошибку без внутренних ответов провайдера.
  Выбор другого ЖК сбрасывает решения, а сохранённый риск остаётся подписан своим ЖК.
- Приоритет очереди и подтверждённый риск визуально и семантически разделены.
  Неоценённый приоритет не заменяется нулём. В реестре серверная сортировка по
  приоритету; подтверждённый риск показан отдельно. Фронтенд не вводит формул риска.
- Анализ запускает серверная очередь после сохранения. Обычная кнопка запуска AI
  убрана также из старых экранов. Явный повтор есть только для failed + canRetry.
  queued/running/quota/unsupported/пустые гипотезы показываются отдельно.
- Источники, расписания, лимиты и запуск сбора сохранены. В новой вкладке удалён
  вводящий в заблуждение старый переключатель немедленного анализа: используется
  единая очередь. Legacy schema источника не менялась. Форма источника не теряется
  при обновлении данных. Скриншот остаётся отдельным допустимым вводом, с проверкой
  MIME/лимита, обработкой конфликтов и сохранением файла для повтора.
- История проверок загружается по запросу, поддерживает cursor/повтор и показывает
  серверное решение, комментарий и имя аналитика; UID не раскрывается. История не
  реконструируется из текущих гипотез.
- Сохранены документы/основания, поиск публичных источников, приватные файлы,
  трассировка старого анализа, компании, карта, дрон, сигналы и PDF. Длинные
  вспомогательные разделы свёрнуты, чтобы не мешать основной проверке.

## Старые ссылки и ограничение контракта

`/advertisements`, `/advertisements/:id`, `/monitoring` с query/item и старые
finding-ссылки открывают канонический раздел либо реальный legacy оригинал.
ID и query не теряются; старые runs доступны внутри вкладки источников.

Контракт не предоставляет resolver legacy advertisement/finding ID → material ID.
Поэтому ссылка на старую запись открывает сохранённую старую запись и переход в
новый список, а не угадывает материал. Нельзя считать первые 20 материалов полным
индексом или подменять legacy ID новым ID. Для бесшовного перехода конкретной
старой записи нужен документированный resolver от B. Старый cursor не совместим
с новой коллекцией: сохраняется как legacyCursor, но не отправляется новому API;
runCursor переносится отдельно. Новый поиск/фильтр сбрасывает новый cursor.

## Воспроизведённые и исправленные регрессии

1. Обновление sources временно размонтировало менеджер и теряло ввод/результат
   действия. Теперь компонент сохраняется при refresh; добавлен регрессионный тест.
2. Обновлённая серверная версия не синхронизировала нетронутую форму. Теперь
   нетронутая форма обновляется, изменённый черновик сохраняется; тесты обоих случаев.
3. Устаревший cursor оставлял пользователя в повторяющейся ошибке. Добавлен явный
   возврат к первой странице с сохранением фильтров; проверен в браузере.
4. Цитата вне первой страницы оригиналов не открывалась без ручного обхода страниц.
   После добавления B exact occurrence endpoint используется адресный запрос;
   проверены retry, отмена устаревшего запроса и выбор правильного оригинала.
5. Предварительные подписи зоны риска могли восприниматься как очередь AI.
   Подтверждённые зоны явно подписаны отдельно; нет процентов готовности стройки.
