# Единые материалы · B / Issue #29

20 октября 2026. Ветка `feat/B-materials-auto-priority`, база main `2751a32`.
Это серверная реализация для параллельного frontend A / #30. Ни frontend,
ни живая инфраструктура не менялись; платных запросов нет.

## Сохранённый этап 1

- Additive `/api/v1/materials`: список/поиск/фильтры/пагинация, detail,
  оригинальные публикации, одно review и retry только ошибочного анализа.
- Проекция в той же транзакции, что ручное объявление/загрузка/публикация
  мониторинга. Исходные коллекции, IDs, решения и приватные файлы сохранены.
  Старые записи подхватываются идемпотентным backfill без reseed.
- Точное нормализованное содержимое группирует повторы; другой текст/фото
  меняет ревизию. Разные явно связанные ЖК не склеиваются по шаблонной подписи.
  Оригиналы/варианты хранятся отдельно, число публикаций не растёт от повторного
  опроса или новой версии одного URL. Результаты изображений привязаны к хешу,
  источник конкретной группы сохраняется даже при использовании анализа из кэша.
- Durable очередь, атомарные lease/общие существующие AI-квоты, ограниченный
  batch. HTTP background ускоряет обработку, действующий worker забирает остаток.
  Неизвестный исход/истёкший lease не вызывает автоматический платный повтор;
  квота оставляет работу в очереди до следующего дня UTC.
- Предварительный приоритет: нерешённый R2=25, R3=10, каждый код один раз;
  low <10, medium 10–24, high >=25. Это отдельная шкала до 35 на текущем наборе
  извлекаемых признаков, не confidence/вероятность/новая формула R1–R6.
  Неоконченный анализ без доступного результата = null/unknown, не «безопасно».
- ЖК получает reviewPriority; sort=priority доступен серверу. Слабое совпадение
  имени даёт кандидата, не подтверждение; приоритет кандидату допустим только
  при единственном совпадении имени и города/адреса в том же scope.
- Review одной транзакцией проверяет версии материала/ЖК, source/scope,
  цитаты/файлы, явные решения и достаточность R2/R3. Сохраняет evidence,
  факторы, human audit и idempotency. Ошибка одного признака откатывает весь
  набор. Чужие подтверждённые источники не стираются при отклонении гипотезы.
- Подтверждённая R1–R6, PDF и старые API остаются прежними. ИИ не подтверждает
  правовой статус и не меняет баллы. Реальные публикации не связываются с DEMO ЖК.

## Ограничения

Внешнее видео/изображение/thumbnail не скачивается автоматически; такие медиа
явно помечены analyzed=false, материал — unsupported после текстового анализа.
Это не просмотр видео. Дрон остаётся отдельным модулем; его наблюдения не
попадают в рекламные R1–R6. В одной группе не более 60 уникальных поддерживаемых
входов анализа. Поиск выполняется серверным paged scan по доступному workspace,
без молчаливой первой страницы/ограниченного результата; для большого реестра
в будущем потребуется специализированный индекс поиска. Cursor связан с
фильтрами/снимком выборки: при изменении возвращается 409, а не пропускаются записи.
