## Реализовано

- Отдельные приватные записи инспекций, оригинал JPEG/PNG/WebP до 6 MiB/20 MP,
  SHA-256, дата загрузки и отдельно указанная пользователем дата съёмки.
- Привязка к существующему ЖК необязательна. Нет автоматического распознавания
  адреса, назначения фотографии похожему ЖК, измерения готовности/этажности.
- Настраиваемый перед созданием чек-лист (1–8 пунктов), необязательная ссылка
  на основание каждого пункта. Начальные примеры — ограждение, знаки безопасности,
  место/контейнер для отходов. Это не утверждённый перечень строительных норм.
- Gemini использует существующую серверную модель/ключ, возвращает строго
  visible/not_visible/uncertain, объяснение, ограничения. Каждый ID чек-листа
  должен встречаться ровно один раз. Ни документ по ссылке, ни нормы не загружаются.
- Явный запуск анализа, общие с рекламным AI дневные квоты, request UUID,
  атомарное резервирование, optimistic version, история запусков и решений.
- Повтор обработки зависшего запуска возможен только явным действием после
  пяти минут; старый поздний результат не перезаписывает новый.
- Человеческое рассмотрение относится к наблюдениям, а не подтверждению
  соблюдения норм. Старый анализ нельзя рассмотреть вместо текущего.
- Все endpoints защищены существующей Auth, workspace-scope и привязкой к ЖК.
  Файлы читаются через API, без public/signed URLs, с проверкой SHA и no-store.
  Неопределённый commit не удаляет потенциально сохранённый оригинал.
- Рекламные доказательства/факторы/правовые основания не меняются.
