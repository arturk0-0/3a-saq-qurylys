## Объём работы

В `/complexes` под основным каталогом добавлен блок **«Карта города»**, по
умолчанию закрытый. Высота карты 360 px, на узком экране — 320 px.
Усть-Каменогорск выбран по умолчанию; город можно переключить в пределах
текущей страницы каталога. Фильтры, таблица, пагинация и авторизация сохранены.
Прежняя карта приоритета остаётся на обзоре `/`.

Здания — одинаковые объёмные SVG-шаблоны с крышей, двумя фасадами и окнами,
Leaflet divIcon. Это условные модели, не реальные контуры, этажность или
план строительства. Нет процентов готовности, этажной шкалы, выделения
построенных этажей или изменения геометрии/цвета по риску.

Берутся существующие записи API со статусом `under_construction`, нужным городом
и конечными координатами в допустимом диапазоне. Неизвестный статус не считается
подтверждённым строительством. Карта показывает статус из карточек, не выполняет
самостоятельную проверку стройки. Координаты не дополняются и не смещаются.
Совпадающая точка даёт одно здание со счётчиком и отдельными ссылками всех ЖК.
Popup содержит имя, адрес, маркировку DEMO по флагу и существующую ссылку ЖК;
данные вставляются через textContent, ID кодируется в URL.

Явно показаны число нанесённых объектов, число без корректных координат,
ограничение текущей страницей/фильтрами и серверный `catalogLimited`.
Первая страница не названа всеми ЖК города. Статус/координаты/данные не
собираются заново; этим отдельно занимается B. Учебные точки условные.

Leaflet и модуль объёмной карты загружаются только после открытия блока с
подходящими объектами. Закрытие удаляет карту и ResizeObserver. При отказе модуля
или тайлов реестр остаётся рабочим. Есть attribution OpenStreetMap; массовой
предзагрузки нет. Колесо прокручивает страницу, перемещение/масштаб доступны
в карте. Выбор здания — мышью либо Tab/Enter. При reduced motion анимация
панорамирования выключена. Popup подвигает только внутреннюю область карты,
чтобы его ссылки помещались даже на ширине 320 px.

## Ограничения и передача B

Это локальная проверка с **явно тестовыми адаптерами**: fake browser Auth,
MemoryStore/FakeFiles/Gemini MockTransport. Граничные наборы координат/статусов
подаются только отдельным browser transport. Успешные тайлы — нейтральная
тестовая сетка; ошибка подложки моделируется искусственным отказом запросов.
Тесты не подтверждают качество/актуальность адресов, полноту города или облако.
Скриншоты должны сохранять подпись тестовых данных/подложки.

После review B проверяет точный CI head, объединяет со своими company-изменениями
и отдельно публикует согласованный SHA. В живом браузере проверить OSM,
реальные подтверждённые координаты, переход карта → ЖК → компания и телефон.
Здесь не проверялись Windows, Safari/Firefox, реальная мобильная клавиатура,
Firebase production/IAM или опубликованная версия. AI/SearchAPI вызовов — 0.
