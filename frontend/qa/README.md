# FE-12: снимки интерфейса для review

**Это локальный Chromium с явно тестовыми AuthContext/API-адаптерами.**
Firebase/Gemini не вызывались, ответы и ошибка сохранения синтетические.
Изображения показывают layout/состояния UI, а не живую интеграционную приёмку.
Временный fixture игнорируется Git и не импортируется production entry.

- [Desktop 1366×768, полная страница](fe12-desktop-test-adapters.png): этапы проверки,
  подтверждённый источник отдельно от AI-происхождения, панель R1–R6.
- [Mobile 375×812, видимая область](fe12-mobile-test-adapters.png): редактор R2,
  сохранённые checkbox/комментарий после тестового отказа. Продолжение формы
  доступно вертикальной прокруткой; страница не выходит за ширину экрана.

Также проверены 1024×768, 768×1024 и 320×700, фокус/cancel, keyboard scroll таблиц,
skip link, отсутствие лишнего POST и сохранение комментария сигнала после refresh
и скачивания тестового Blob. Подробный результат: [отчёт](../../docs/night-frontend-report.md).
