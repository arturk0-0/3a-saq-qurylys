# SAQ QURYLYS · ALEteam

Веб-приложение для аналитиков ВКО: сбор рекламы жилья, проверка источников и
документов, объяснимый приоритет R1–R6, решение аналитика и сигнал с PDF.
ИИ предлагает признаки; подтверждённый балл считает сервер. Высокий приоритет
требует проверки и сам по себе не устанавливает нарушение.

## Быстрый запуск для организаторов — без ключей

Нужны **Git и Docker Desktop / Docker Engine с Compose v2**. На Windows включите
Linux containers и дождитесь запуска Docker Desktop. Скачивание образов и зависимостей
при первой сборке требует Интернета. После сборки локальный деморежим не использует
Firebase, Gemini или SearchAPI и не требует аккаунтов облачных сервисов.

```bash
git clone https://github.com/arturk0-0/3a-saq-qurylys.git
cd 3a-saq-qurylys
docker compose -f compose.demo.yaml up --build --wait --wait-timeout 180
```

Откройте **http://localhost:5173**.

| Поле входа | Значение только для локальной демонстрации |
| --- | --- |
| Почта | `analyst@example.test` |
| Пароль | `demo-demo` |

Создавать `.env`, включать Firebase или загружать Admin JSON не нужно. Деморежим
содержит **8 вымышленных ЖК и 12 объявлений**, учебную очередь мониторинга и
страницы вымышленных компаний. Числа A/B/C: **35 / 70 / 10 баллов**.

Можно пройти каталог, карту с шаблонными зданиями, рекламный след, проверку
источника и факторов, полный цикл сигнала, PDF, загрузку скриншота и дрон-фото.
**Анализ и сбор здесь учебные:** текст обрабатывается простыми локальными правилами,
скриншоты сохраняются без распознавания, фотоосмотр возвращает «нельзя определить».
Это явно указано в интерфейсе и результатах. Реальные Gemini и источники доступны
в облачном режиме. Внешние справочники в локальном режиме не опрашиваются.

Изменения и файлы сохраняются в отдельном Docker volume. Для остановки:

```bash
docker compose -f compose.demo.yaml down
```

Для **полного удаления только локальных учебных данных**:

```bash
docker compose -f compose.demo.yaml down -v
```

Заняты 8000 или 5173? Остановите предыдущую копию SAQ или другое приложение на
этих портах. Не запускайте `compose.yaml` и `compose.demo.yaml` одновременно.

Автоматическая проверка (необязательно; нужен Python 3.12+ на хосте):

```bash
python scripts/check-local-demo.py
```

Проверяются вход, данные, локальные гипотезы, ручное подтверждение, **35 баллов**,
возврат/подтверждение сигнала, настоящий PDF, приватная загрузка и выход. Проверка
создаёт отдельный вымышленный объект и не сбрасывает решения в существующих.
Подробности: [локальный режим и его границы](docs/local-demo.md).

## Возможности

- Telegram из выбранных публичных каналов и Instagram-реклама из Meta Ad Library
  через SearchAPI: настраиваемые источники, очередь находок, расписание и лимиты.
- Карточка ЖК: документы, доказательства, рекламный след и объяснение R1–R6.
- Проверка применимости разрешения/гарантии: кандидаты Homeportal/Ashyq,
  решение человека с историей. Отсутствие записи не подтверждает отсутствие права.
- Юридический застройщик и уполномоченная компания: БИН, известные факты и ссылки
  на источники Homeportal/ADATA; неизвестные сведения не выдумываются.
- Вторичная карта города с одинаковыми объёмными маркерами на известных координатах.
  Они не показывают фактическую этажность или процент готовности.
- Текст/скриншоты с Gemini, отдельная проверка аналитиком, детерминированный риск.
- Сигналы: черновик → проверка → подтверждение/возврат, версии, история, PDF.
- Дрон-инспекция: приватное фото, редактируемый визуальный чек-лист, наблюдения
  ИИ и отдельное решение эксперта. Фото не устанавливает соблюдение всех норм.

## Запуск с настоящими Firebase и Gemini

Это отдельная конфигурация, если нужен собственный полноценный экземпляр.
Инструкции: [Firebase, роль и данные](docs/firebase-setup.md),
[Windows](docs/windows-start.md), [публикация](docs/cloud-deployment.md).

Для Docker из корня, после заполнения `.env` и приватного пути credentials:

```bash
docker compose -f compose.yaml -f compose.firebase.yaml up --build --wait
```

Без Firebase основной `compose.yaml` запускает только health и экран подключения.
Рабочее пространство требует действительные Firebase ID token и роль analyst/admin;
режим демонстрации не является обходом облачной авторизации. Закрытые Firestore/
Storage rules и серверные проверки сохраняются. `.env` и приватные ключи не входят в Git.

Для нативной разработки нужны **Python 3.12, uv 0.12.23, Node.js 24 LTS**.
Установка по lockfiles: `uv sync --frozen` из `backend/`, `npm ci` из `frontend/`.
Для PDF на Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz-subset0 fonts-dejavu-core
```

Два терминала, из соответствующих директорий:

```bash
# backend/
uv run --frozen uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```bash
# frontend/
npm run dev
```

Нативная локальная демонстрация: вместо этих команд `uv run --frozen python -m
local_demo` из `backend/` и `npm run demo` из `frontend/`. Её данные находятся в
`backend/.local-demo-data/`; папка не входит в Git. Облачные `.env` игнорируются
демоадаптерами. Детали и проверка изоляции: [local-demo.md](docs/local-demo.md).
