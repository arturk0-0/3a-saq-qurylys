# DEMO dataset v1

Все названия, БИН, адреса, публикации, документы и результаты проверок вымышлены.
Координаты обозначают город демонстрации, а не реальный строительный объект.
`demo.invalid` — заведомо несуществующий источник. `DEMO-fictional-reviewer` — вымышленный
проверяющий, а не реальный пользователь Firebase.

8 ЖК, 8 застройщиков, 12 объявлений, документальные DEMO-доказательства и сценарии:
A — 35/YELLOW, B — 70/RED, C — 10/GREEN с действующей применимой гарантией.

Генератор: `backend/app/services/seed_data.py`. Из `backend/`:

```bash
uv run --frozen python -m app.cli.seed validate
uv run --frozen python -m app.cli.seed export --output ../data/seed/demo.json
```

Эти команды проверяют/экспортируют JSON и не обращаются к Firebase.
Существующая работа аналитиков не должна перезаписываться при последующей загрузке seed.
